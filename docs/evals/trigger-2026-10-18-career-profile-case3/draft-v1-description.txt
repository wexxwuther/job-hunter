Sets up the user's job-search profile and reads their resume so the rest of a job hunt has real context. Use whenever the user wants to set up or update their job-search profile, tell the assistant about themselves, answer the North-Star intake questions (role archetype, deal-breakers, company size, mission vs comp, on-call/travel/office tolerance), or refresh a stale profile, and whenever they share a resume file (DOCX, PDF, MD, TXT, HTML) to read, parse, or pull key facts from for later use, even a short ask; load it rather than reading and summarizing the file yourself, which saves no profile for later steps (for a resume, prefer this over a generic DOCX or PDF skill). Produces a local .job-hunter-profile.md and parsed-resume text. Do not use for tailoring a resume to a specific posting or running a keyword-gap analysis (use resume-tailor), finding or scoring job postings (use job-search), tracking applications or follow-ups (use application-tracker), or generic resume critique with no job search underway.
